# 🎓 Student Management System

A web-based Student Management System developed using **Python Flask, HTML, CSS, and SQLite** to efficiently manage student records.

## 🚀 Features

- ➕ Add new student records
- 👀 View all student records
- ✏️ Edit and update student information
- 🗑️ Delete student records with confirmation
- 🔍 Search students by name, roll number, or email
- 🎓 Filter students by course
- 📊 Dashboard with student statistics
- 📱 Responsive and user-friendly interface

## 🛠️ Technologies Used

- **Python**
- **Flask**
- **HTML5**
- **CSS3**
- **SQLite**
- **Jinja2**
- **Gunicorn**

## 💾 Database

The application uses **SQLite** to store student information, including:

- Student ID
- Roll Number
- Student Name
- Email
- Phone Number
- Course
- Academic Year
